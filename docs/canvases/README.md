# Shared Cursor canvases

This directory stores portable source copies of the team's Cursor canvases.

Cursor renders a canvas only when its `.canvas.tsx` file is copied into the
managed `canvases/` directory for the current workspace. After cloning or
pulling this repository, ask Cursor:

> Install `@docs/canvases/traffic-signal-control-research.canvas.tsx` as a
> canvas for this workspace without modifying its contents.

The repository copy is the version-controlled source of truth. When updating a
canvas, update this copy in the same commit.
